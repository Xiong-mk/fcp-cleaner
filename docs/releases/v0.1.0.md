# FCP Cleaner v0.1.0 — ad-hoc 预发布测试版

隐私修订版，应用版本 **0.1.0（构建 2）**，替代最初发布的构建 1。线上托管及正式更新源验收结果以 [发布清单](https://github.com/Xiong-mk/fcp-cleaner/blob/main/docs/release.md) 为准。

原生 macOS Final Cut Pro 资源库缓存管理工具。支持系统文件夹授权、包内两类缓存统计、默认未选的清理预览、原始快照复验、退出 FCP 与二次确认、逐项移到系统废纸篓、日志和完成后重扫。

- 支持 macOS **14.0+**，应用为 **Apple Silicon / Intel 通用版本**。
- 本版采用 **ad-hoc 签名，未经过 Apple 公证**。其他 Mac 上的 Gatekeeper、最低系统和实际升级安装尚未验收；不建议关闭系统安全设置。
- 更新 ZIP：`FCP-Cleaner-0.1.0.zip`。对应源码：`FCP-Cleaner-v0.1.0-source.zip`，另附 SHA-256、源码 manifest 和更新包元数据。
- 集成 Sparkle 2.10.0，更新源为 `https://Xiong-mk.github.io/fcp-cleaner/appcast.xml`。自动检查默认开启，自动下载默认关闭。
- 许可证 **GPL-3.0-or-later**；完整对应源码、构建脚本、许可资料和第三方声明随源码附件及标签提供。

只匹配 `<库>.fcpbundle/<事件>/Render Files/High Quality Media` 与 `Analysis Files`，要求资源库是授权父文件夹的直接子项。不处理原始素材、代理/优化媒体、数据库、备份或外部缓存；不能区分「仅未使用渲染」。清理后 Final Cut Pro 可能需要重新渲染或分析。

估算占用与移入废纸篓容量均不等于已释放空间。系统废纸篓失败不会降级为永久删除。使用前请阅读 [README](https://github.com/Xiong-mk/fcp-cleaner/tree/v0.1.0#readme) 中的使用流程与边界。

此次修订改用中性构建路径和编译器路径映射，清理安装包本机目录元数据，保留 DMG 安装布局；补充暂存区与发布隐私检查，并校准自动更新说明。构建号 2 高于原构建 1，沿用原 Sparkle 公钥。签名和版本比较验证不等于真实升级安装与重启已通过；完整升级仍需单独验收。独立 macOS 14、Intel Mac、真实外接盘和可丢弃真实 FCP 测试库仍需设备验收。
