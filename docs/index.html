清理范围

只统计资源库包内事件目录中的 Render Files/High Quality Media 和 Analysis Files。不处理原始素材、代理或优化媒体、数据库、备份与外部缓存，也不能区分未使用的渲染。

清理前请退出 Final Cut Pro，核对预览并完成二次确认。后续可能需要重新渲染或分析。估算容量不等于实际释放空间；移入废纸篓失败时不会改用永久删除。
